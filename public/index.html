About

CoCanvas is a free, instant real-time collaborative whiteboard, live coding workspace, and visual canvas.

Create multiplayer rooms in 1 click, sketch diagrams, write and format code with our smart IDE compiler, brainstorm with sticky notes, and present seamlessly in Host Mode without login friction!

Enjoy voice chat, laser pointers, live cursor chat, prebuilt templates, and 2x HD Retina export. Have fun collaborating!
