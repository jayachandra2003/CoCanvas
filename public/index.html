About

CoCanvas is a free, instant real-time collaborative whiteboard, live coding workspace, and multi-page visual canvas.

Switch between Fixed Page Mode for clean multi-page presentations and Playground Mode for infinite drawing! Sketch with 9 MS Paint brushes, code in real-time, brainstorm with sticky notes, and present seamlessly in Host Mode.

Enjoy continuous voice typing with live translation, page-isolated collaborators, laser pointers, stickers, chat, and 2x HD Retina export. Have fun collaborating!

📟

News & Updates

Latest Updates Version 4.0
  • 📄Fixed Multi-Page Mode: Dedicated multi-page canvas with page-isolated drawings, bottom dock & fit-to-window
  • 🎓Smart Presentation Sync: Host Mode syncs page flips & mode switches to viewers; Friendly Mode allows independent navigation
  • 🎯Page-Isolated Collaborators: Cursors, live drafts, laser trails & reactions are isolated to the active page
  • 🔔Compact Top-Right Toasts: Redesigned sleek notifications docked under top bar with smooth slide animation
  • 🎙️Multi-Language Voice Typing: Speaks in any language & auto-translates to English in real time
  • 🛡️2-Kick Anti-Abuse Ban: Host kick tracking with permanent room ban protection
  • 👥Room Members & Roles Hub: Top-right modal to manage hosts, jump to view & kick users
  • 🎨MS Paint Brushes & Stickers: 9 realistic brushes, custom photo avatars, emoji stickers & palettes
  • 💻Smart IDE Code Compiler: Real-time collaborative code editor with syntax formatting
